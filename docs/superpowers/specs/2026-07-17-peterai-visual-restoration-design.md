# PeterAI 官网视觉回归设计

## 目标

以本轮 GEO 改造前的 Git HEAD 版本为唯一视觉基准，恢复深色科技感、玻璃面板、人物主视觉、金色与青色配色、原首页组件顺序和信息密度，同时完整保留已经实现的 GEO 技术能力与十个独立页面。

## 不变项

- 保留构建期静态预渲染和十个公开路由。
- 保留每页独立的 title、description、canonical、Open Graph 和 JSON-LD。
- 保留 robots.txt、sitemap.xml、Organization、LocalBusiness、Service 和 FAQPage 数据。
- 保留品牌实体定义、服务边界、脱敏案例表达和禁用虚假稀缺文案的测试。
- 不提交、不推送、不发布。

## 首页视觉

首页重新使用改造前的 `Navbar`、`HeroSection`、`Timeline`、`PainPoints`、`FitCheck`、`DeliveryLoop`、`OrgChart`、`Cases`、`LogicMoat` 和 `CTA`。组件顺序、人物图片、玻璃面板、全息图标、深色背景及金青配色保持原样。

首页首屏增加可见的公司全称和稳定服务定义，以满足品牌实体表达。原视觉中的虚构仪表盘数字改为“诊断中、试点、人工接管”等状态词；联系模块移除价格锚点、限额和免费名额，但保留原二维码卡片结构。

## 内页视觉

服务页、行业页、案例、FAQ、关于和联系页继续共用现有内容模型，但改用原站的视觉词汇：`hero-dashboard` 作为页面头部容器，`glass-panel` 与 `glass-panel-soft` 承载要点和正文，`glass-chip` 表达标签，金色用于关键动作，青色用于流程与可信信息。

所有内页继续输出完整静态正文，不把关键内容藏进交互状态。FAQ 第一条默认展开，其余内容使用原生 details，关闭 JavaScript 仍可访问。

## 响应式与验收

- 1440x900 首页视觉结构与改造前保持一致，人物主视觉、六个能力图标和证明条可见。
- 390x844 首页不横向溢出，导航、按钮、标题和人物图片不重叠。
- 十个页面在 390px 宽度下无横向溢出、图片失败或控制台错误。
- 自动测试同时验证原视觉标识和全部 GEO 输出。
